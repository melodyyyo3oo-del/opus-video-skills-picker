# Opus 5.5 视频挑选台

**在线浏览：https://melodyyyo3oo-del.github.io/opus-video-skills-picker/**

一个帮你挑选「用 Claude Opus 5.5 做视频」开源资源的页面。它把 8 个热门仓库放在一起，配上效果图、可以播放的样片和风格简介，方便你按想做的片子挑一个 skill、风格或提示词。

页面上的片子都是 Opus 5.5 写代码逐帧渲染出来的（Canvas、SVG、Three.js、p5.js、Remotion 等），没有用视频生成模型。
